# API SmartDelivery

## Общая информация

Базовый URL:
```
/api
```

API сервиса SmartDelivery позволяет управлять заказами: создавать, получать, обновлять статус и просматривать список заказов.

---

# 📦 1. Создание заказа

## POST /api/orders

Создаёт новый заказ.

### Запрос

```json
{
  "title": "Заказ еды",
  "body": "Доставка пиццы",
  "userId": 1
}
```

### Ответ

```json
{
  "id": 101,
  "title": "Заказ еды",
  "body": "Доставка пиццы",
  "userId": 1
}
```

---

# 🔍 2. Получение заказа

## GET /api/orders/{id}

Получение информации о конкретном заказе.

### Ответ

```json
{
  "id": 1,
  "title": "Заказ еды",
  "body": "Доставка пиццы",
  "userId": 1
}
```

---

# ✏️ 3. Обновление статуса заказа

## PUT /api/orders/{id}/status

Обновляет статус заказа.

### Запрос

```json
{
  "status": "delivered"
}
```

### Ответ

```json
{
  "message": "Статус заказа обновлён"
}
```

---

# 📋 4. Список заказов

## GET /api/orders

Возвращает список всех заказов.

### Ответ

```json
[
  {
    "id": 1,
    "title": "Заказ 1"
  },
  {
    "id": 2,
    "title": "Заказ 2"
  }
]
```
