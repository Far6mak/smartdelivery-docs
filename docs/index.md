# SmartDelivery API

## 📦 О проекте

SmartDelivery — учебный проект, который демонстрирует документирование REST API сервиса доставки.

В проекте реализовано:
- описание API
- архитектурные диаграммы (Mermaid)
- примеры запросов и ответов
- автоматические тесты API
- документация через MkDocs

---

## 🚀 Возможности

- Создание заказа
- Получение информации о заказе
- Обновление статуса заказа
- Удаление заказа
- Автоматическое тестирование API

---

## 🧠 Технологии

- Python
- REST API
- JSONPlaceholder (тестовый сервис)
- MkDocs
- Mermaid диаграммы
