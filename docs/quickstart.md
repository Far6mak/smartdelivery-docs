# Быстрый старт

## 📥 Установка зависимостей

Установите Python-библиотеку для работы с API:

```bash
pip install requests
```

---

## 🚀 Запуск тестов

### Вариант 1 — напрямую

```bash
python tests/api_tests.py
```

---

### Вариант 2 — через скрипт

Linux / Mac:

```bash
bash tests/run_tests.sh
```

Windows:

```bash
tests/run_tests.bat
```

---

## 🌐 Запуск документации

```bash
mkdocs serve
```

После запуска открой:

```
http://127.0.0.1:8000
```

---

## 📌 Сборка документации

```bash
mkdocs build
```

---

## 🧠 Что дальше

После запуска можно:
- изучить API в разделе "API"
- посмотреть архитектуру системы
- запустить тесты
